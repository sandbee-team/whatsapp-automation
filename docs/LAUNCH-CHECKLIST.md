## How to use this file

Walk rows in order. Each row with Status `NOT DONE` blocks launch unless the founder signs an exception in writing. For rows 4 and 5, re-time at every 3x growth in connected numbers (start at 100 sessions for dev-box drills; re-run on production when load reaches 300, 900, etc.). Evidence paths are checked at gate closure; if a path does not exist when you close the gate, the gate fails.

## Evidence directory conventions

- `docs/evidence/` — phase-specific results (drills, security scans, integration test summaries)
- `docs/capacity/` — Gates A and B artefacts (session cost, fleet ceiling)
- `docs/measurements/` — machine-written JSON (timing data, load curves, profiler output)
